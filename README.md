# _davCONVERT

_davCONVERT è il convertitore locale multipiattaforma della suite _davstudios. La release stabile v1.0.0 include conversione batch reale per immagini statiche, drag & drop, scelta del formato, qualità JPEG, cartella di destinazione e coda risultati.

## Formati supportati

Input/output: PNG, JPG/JPEG, WEBP, BMP, TIFF/TIF e ICO. La conversione avviene interamente in locale tramite il backend Rust.

Audio, video e documenti potranno essere aggiunti nelle versioni successive senza modificare la base stabile della v1.0.0.

## Funzioni principali

- Conversione batch locale.
- Drag & drop e selettore file nativo.
- Formato di uscita configurabile.
- Qualità JPEG regolabile.
- Cartella di destinazione automatica o personalizzata.
- Gestione dei file omonimi.
- Coda con stato, errori e risultati per file.
- Tema Sistema / Chiaro / Scuro e interfaccia Italiano / English.
- Design system e motion coerenti con la suite _davstudios.

## Avvio

Su Windows esegui `RUN-WINDOWS.bat`. Su macOS/Linux usa gli script `RUN-*` corrispondenti.
